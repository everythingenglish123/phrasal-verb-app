# ⏰ Daily Routines
## Folder: 25 - routines

**Status:** 🔧 Needs audio
**Verbs:** 8

## Required filenames

Drop `.mp3` files in this folder using these EXACT names. The app reads the path:
`audio/25 - routines/<NN>-<verb-slug>.mp3`

| # | Verb | Filename to use |
|---|------|-----------------|
| 01 | wake up | `01-wake-up.mp3` |
| 02 | get up | `02-get-up.mp3` |
| 03 | sleep in | `03-sleep-in.mp3` |
| 04 | put on | `04-put-on.mp3` |
| 05 | take off | `05-take-off.mp3` |
| 06 | meet up | `06-meet-up.mp3` |
| 07 | eat out | `07-eat-out.mp3` |
| 08 | stay up | `08-stay-up.mp3` |

## Naming rules
- Two-digit prefix (`01`, `02`, … not `1`, `2`)
- All lowercase, spaces become hyphens
- Strip parenthetical disambiguations (e.g. `take off (clothing)` → `take-off`)
- Extension is `.mp3` (lowercase)
