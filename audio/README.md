# News Audio Folders — Master Index

This folder holds the news-snippet audio files that play when learners open a verb's news card. Each phrasal-verb unit has its own subfolder.

## How the app finds audio

Every verb in `phrasal-verbs-sample.html` has a `newsAudio` field that points at a path like:
`audio/<num> - <shortname>/<NN>-<verb-slug>.mp3`

If the file exists at that path, the app plays it. If it doesn't, the player just shows nothing for that verb. **No code changes are needed when you drop new files in.**

## Drag-and-drop workflow

1. Open the folder for the unit you're working on.
2. Read its `README.md` for the exact filename list.
3. Drop your generated `.mp3` files into that folder.
4. Reload the app — the audio works immediately. No code changes.

## Naming rules (universal)

- `<NN>-<verb-slug>.mp3`
- `<NN>` is a 2-digit number matching the verb's order in the unit (`01`, `02`, … `18`)
- `<verb-slug>` is the verb name lowercased with spaces replaced by hyphens
- Parentheticals are stripped: `take off (airplane departs)` → `take-off`
- Extension `.mp3` (lowercase)

## Examples
- `audio/15 - crime/02-pull-over.mp3`
- `audio/18 - elections/01-run-for.mp3`
- `audio/22 - conversations/13-team-up-with.mp3`
