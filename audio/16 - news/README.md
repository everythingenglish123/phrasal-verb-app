## Naming rules
- Two-digit prefix (`01`, `02`, … not `1`, `2`)
- All lowercase, spaces become hyphens
- Strip parenthetical disambiguations (e.g. `take off (clothing)` → `take-off`)
- Extension is `.mp3` (lowercase)
